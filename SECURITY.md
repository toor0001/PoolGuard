# Security Policy

## Reporting a vulnerability

Please do not disclose vulnerabilities, credentials, personal data or detailed
exploitation steps in a public issue.

Use GitHub's private vulnerability reporting for this repository, if available:

https://github.com/toor0001/PoolGuard/security/advisories/new

Include the affected revision, a concise description, reproduction information
and the potential impact. Remove real Wi-Fi credentials, ESPHome API encryption
keys, OTA passwords, tokens, addresses and other personal data from logs or
attachments before submitting them.

If private vulnerability reporting is unavailable, contact the repository owner
through their public GitHub profile without posting sensitive technical details.

## Scope

Security reports concerning the PoolGuard firmware, its documented Home
Assistant integration and accidental credential exposure in this repository are
welcome. General installation questions and non-sensitive bug reports may use
the public issue tracker.
